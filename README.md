# CloudVinn Pterodactyl Theme

Custom theme untuk Pterodactyl Panel dengan konsep futuristic cyber-glass.

## Features

- Custom CloudVinn server sidebar
- Cyber / futuristic UI
- Glassmorphism styling
- Custom GTA-style console background
- Transparent console
- Custom server navigation
- phpMyAdmin shortcut pada Database
- Responsive server navigation
- Tidak mengubah database/customer
- Tidak mengubah `.env`

## Requirements

- Pterodactyl Panel
- Linux
- PHP
- Node.js
- npm
- Root access
